# Telegram_exported_chathistory_viewer

Скрипт/программа для просмотра экспортированных чатов и каналов.
Интерфейс повторяет интерфейс телеграмма, только нет возможности писать сообщения.
к сожелению телеграм не экспартирует аватарки, придётся заменить их первыми буквами ника, и по очереди выставлять фон оранжнвый, красный, синий, зелёный, фиолетовый.

Реализованные функции:
Просмтр видео, просмотр фото, просмотр даты сообщения, поддержка стикеров из тг, анимированных стикеров из тг, гиф. поиск по всем экспортированым чатам, поиск по чату, поиск по словам, поиск по дате.
